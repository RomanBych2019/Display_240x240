# Display 240x240

Прошивка дисплея 240x240 для системы CNG/EVO на базе ESP32-C3. Устройство читает данные автомобиля и газового блока по CAN, отображает телеметрию на TFT-дисплее, рассчитывает показатели экономичного вождения и поднимает локальный Wi-Fi веб-портал для просмотра параметров, настройки страниц дисплея, загрузки файлов и OTA-обновления.

## Возможности

- Прием CAN-данных EVO и J1939: обороты, скорость, пробег, расход ДТ, температуры, нагрузка двигателя, вес автомобиля, параметры CNG.
- Отображение страниц на круглом/квадратном TFT 240x240: CNG, параметры EVO, кнопка газ/ДТ, уровень топлива, соленоиды, потеря связи с EVO.
- Переключение пользовательских страниц жестами тач-контроллера CST816D.
- Долгое нажатие на странице кнопки газ/ДТ отправляет CAN-команду включения/выключения газа.
- Расчет уровня экономичного вождения по карте `ACC/RPM`.
- Расчет среднего расхода газа и примерного остаточного пробега.
- Веб-портал в режиме Wi-Fi AP для телеметрии и настроек.
- OTA-обновление через GyverPortal.
- Контроль перегрева ESP32: при высокой температуре снижается мощность Wi-Fi, частота обновления и яркость дисплея.

## Аппаратная платформа

- MCU: `ESP32-C3 DevKitM-1`
- Framework: Arduino
- Дисплей: TFT 240x240, драйвер `GC9A01`, библиотека `TFT_eSPI`
- Тач-контроллер: `CST816D`
- CAN: TWAI ESP32-C3, библиотека `ESP32-TWAI-CAN`
- Файловая система: `LittleFS`

### Основные пины

| Узел | Сигнал | GPIO |
| --- | --- | --- |
| CAN | RX | `GPIO20` |
| CAN | TX | `GPIO21` |
| Touch I2C | SDA | `GPIO4` |
| Touch I2C | SCL | `GPIO5` |
| Touch | INT | `GPIO0` |
| Touch | RST | `GPIO1` |
| TFT SPI | MOSI | `GPIO7` |
| TFT SPI | SCLK | `GPIO6` |
| TFT | CS | `GPIO10` |
| TFT | DC | `GPIO2` |
| TFT | BL | `GPIO3` |
| TFT | RST | `-1` |

Пины TFT задаются в локальной копии библиотеки: `lib/TFT_eSPI-master/User_Setup.h`.

## Сборка и прошивка

Проект собирается через PlatformIO.

```bash
pio run
```

Загрузка прошивки:

```bash
pio run --target upload
```

Загрузка файлов LittleFS из папки `data/`:

```bash
pio run --target uploadfs
```

Монитор порта:

```bash
pio device monitor
```

Основное окружение PlatformIO:

- `env:esp32-c3-devkitm-1`
- `platform = espressif32@5.3.0`
- `board = esp32-c3-devkitm-1`
- `framework = arduino`
- `board_build.partitions = partition.csv`
- `board_build.filesystem = littlefs`
- `monitor_speed = 115200`
- USB CDC включен на старте через `ARDUINO_USB_CDC_ON_BOOT=1`

## Wi-Fi и веб-портал

После запуска устройство поднимает точку доступа:

- SSID: `DisplayEVO`
- Пароль: `00000001`

Веб-портал построен на `GyverPortal`. Через него доступны:

- вкладка телеметрии автомобиля и EVO;
- выбор скорости CAN-шины;
- выбор типа автомобиля;
- настройка объема газовых баллонов;
- включение/отключение страниц дисплея;
- загрузка карты `Map_ACC-RPM.csv`;
- OTA-обновление.

Данные для OTA:

- Логин: `ItalGaz`
- Пароль: `001`

## Файлы LittleFS

Содержимое папки `data/` загружается во flash-файловую систему устройства.

| Файл | Назначение |
| --- | --- |
| `Map_ACC-RPM.csv` | Карта оценки экономичности по педали ACC и RPM |
| `Error_EVO_new.csv` | Справочник ошибок EVO |
| `screen*.png` | PNG-экраны/графика для отображения |
| `display_config.json` | Настройки дисплея и автомобиля, создаются/обновляются прошивкой |

Если `display_config.json` отсутствует, прошивка использует значения по умолчанию из `src/main.cpp` и `src/can_settings.h`.

## CAN-данные

Прошивка принимает расширенные CAN-кадры EVO и стандартные J1939 PGN автомобиля. Основные идентификаторы описаны в `src/can_settings.h`.

### Входящие EVO

| ID | Назначение |
| --- | --- |
| `0x18FFF0BB` | состояние газ/ДТ, ACC, впрыск газа, давление, температуры |
| `0x18FFF1BB` | уровень CNG и температура редуктора |
| `0x18FFFBBB` | ошибки EVO и версия |
| `0x18FFF8BB` | расход газа за поездку и общий расход |
| `0x18FFFAA1` | состояние и токи соленоидов |
| `0x18FFFBA1` | уровень дизельного топлива |

### Входящие J1939

| PGN | Назначение |
| --- | --- |
| `0xFEF1` | скорость автомобиля |
| `0xFEC1` | пробег |
| `0xFEF2` | мгновенный расход ДТ |
| `0xF004` | обороты и нагрузка двигателя |
| `0xFEF6` | температуры воздуха/выхлопа |
| `0xFEEE` | температуры ОЖ, масла, топлива |
| `0xFEEA` | вес автомобиля |

### Исходящие CAN

| ID | Назначение |
| --- | --- |
| `0x18FFEEDD` | команда включения/выключения газа |
| `0x18FFFEDD` | диагностические данные дисплея: экономичность, средний расход, запас хода, объем баллонов |

## Структура проекта

```text
.
├── data/                  # файлы LittleFS
├── display/               # графические исходники дисплея
├── docs/                  # документация, схемы, платы, даташиты
├── include/               # стандартная папка PlatformIO
├── lib/                   # локальные библиотеки проекта
├── src/                   # исходный код прошивки
├── test/                  # стандартная папка PlatformIO
├── platformio.ini         # настройки сборки
├── partition.csv          # разметка flash
├── max_app_4MB.csv        # альтернативная разметка
└── min_spiffs.csv         # альтернативная разметка
```

Ключевые файлы в `src/`:

- `main.cpp`, `main.h` - запуск, задачи FreeRTOS, обработка CAN, расчеты, LittleFS-настройки.
- `TFT_240_240.cpp`, `TFT_240_240.h` - отрисовка страниц TFT-дисплея.
- `WebPortal.cpp`, `WebPortal.h` - Wi-Fi AP, веб-интерфейс, OTA, загрузка файлов.
- `CST816D.cpp`, `CST816D.h` - работа с тач-контроллером.
- `can_settings.h` - структура CAN-данных и PGN/ID.
- `DisplayConfig.h` - описание страниц дисплея.
- `PNG_FS_Support.cpp`, `PNG_FS_Support.h` - вывод PNG из файловой системы.
- `SolenoidHealth.h` - состояния соленоидов.

## Настройка страниц дисплея

Начальная конфигурация страниц задается в `src/main.cpp` в объекте `g_displayConfig`.

Доступные страницы:

- `CNG`
- `Параметры EVO`
- `Кнопка газ/дт`
- `Уровень топлива`
- `Соленоиды`
- `EVO Lost`

Веб-портал может включать и отключать пользовательские страницы. Системная страница `EVO Lost` используется для индикации потери связи с газовым блоком.

## Примечания для разработки

- Перед проверкой работы на устройстве прошивайте и firmware, и LittleFS.
- При изменении пинов дисплея правьте `lib/TFT_eSPI-master/User_Setup.h`.
- При изменении формата CAN-данных сначала обновляйте `src/can_settings.h`, затем парсинг в `analise_can_id()`.
- Для настройки жестов не удаляйте лог `Touch: x=..., y=..., gesture=...` в `src/main.cpp`: он нужен для проверки координат и распознавания жестов.
- В репозитории есть `.DS_Store` и `Thumbs.db`; они не нужны для сборки.
